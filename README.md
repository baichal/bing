一个 Tampermonkey / Violentmonkey 油猴脚本：用今日热榜关键词在 Bing 上自动搜索刷积分，悬浮窗控制台操作，**搜索在后台标签页进行，不抢占你当前正在看的页面**。

## 🛠️ 功能特性

- **热榜关键词搜索**：从 [NewsNow](https://newsnow.busiyi.world) 拉取今日热榜作为搜索词，内置 19 个榜单，默认「🔥最热聚合」（多源合并去重）。
- **后台搜索，不抢焦点**：所有搜索都在一个后台标签页里完成，你当前浏览的页面不会被跳转或抢走焦点。
- **智能积分检测**：对比每次搜索前后的积分；连续 N 次无积分增长自动停止（可在面板设置阈值），防止无效刷分和风控。
- **自动换榜**：当前榜单搜完后自动切到下一榜单；跨天自动随机换榜。
- **随机延迟**：每次搜索间隔 8~14 秒随机，模拟真人节奏。
- **多标签互斥**：多标签打开时只有一个主控负责调度，避免重复运行。
- **防死循环**：命令去重 + URL 规范化 + 主控心跳检测，主控关闭后后台标签不会无限刷新。
- **可拖拽悬浮窗**：支持折叠、深色模式（跟随系统 / Bing 深色）。

> 说明：本版本为**纯搜索版**，已移除早期版本中的 Rewards 每日任务自动点击与定时启动功能，仅保留手动开始。

## 🚀 安装

1. 安装浏览器扩展：**Tampermonkey**（油猴）或 **Violentmonkey**（暴力猴）。
   - 若 Tampermonkey 出现「没有访问此页面的权限」或脚本不注入，可改用 Violentmonkey。
2. 点击扩展图标 → 「添加新脚本 / 管理面板 → 新建」。
3. 删除编辑器默认内容，将本仓库 [`auto_bing.js`](auto_bing.js) 的**全部内容**粘贴进去。
4. 保存（`Ctrl + S`）。
5. 打开 [www.bing.com](https://www.bing.com) 或任意 Bing 搜索页，即可看到右下角悬浮窗。

## 📖 使用说明

### 悬浮窗控制项

| 项目 | 说明 |
| --- | --- |
| **榜单** | 选择搜索词来源（默认「🔥最热聚合」，另有微博/知乎/百度/抖音/B站等 18 个榜单） |
| **点击** | 关键词的打开方式：搜索（在 Bing 搜索该词）/ 打开（打开原文链接） |
| **有效搜** | 左为今日已完成的有效搜索次数，右侧输入框为目标次数（默认 50） |
| **失败停** | 连续多少次搜索未增加积分后自动停止（默认 10） |
| **开始 / 停止** | 手动启动或停止自动搜索 |

### 推荐流程

1. 打开 Bing 搜索页。
2. 选择榜单，设置「有效搜」目标次数（仅 PC 建议 30~35，含移动端可设 50）。
3. 点击 **开始** —— 脚本会新建一个后台标签页并在其中自动搜索，当前页面不受影响。
4. 达到目标次数或连续无分达阈值后自动停止。

### 工作原理

- **主控页**：你当前打开的 Bing 页面，只负责悬浮窗展示和调度决策，自身永不跳转。
- **后台 Worker**：一个带 `__rbw=1` 标记的后台标签页，真正执行搜索导航并上报积分。
- 两者通过 GM 存储的命令通道协作；关闭主控页后 worker 自动待命，不会空转刷新。

### 常见问题

- **Q：为什么提示「等待冷却」？** A：为避免风控，每次搜索后随机等待 8~14 秒，属正常现象。
- **Q：积分不涨了？** A：可能今日已达上限、服务端延迟或账号进入冷却期；连续无分达到「失败停」阈值会自动停止保护账号。
- **Q：右侧多了一个标签页？** A：那是后台 Worker，用于在不抢焦点的情况执行搜索，属正常现象。
- **Q：悬浮窗怎么收起？** A：点标题栏右侧的 `−` 折叠，`+` 展开；位置可拖动并自动记忆。
